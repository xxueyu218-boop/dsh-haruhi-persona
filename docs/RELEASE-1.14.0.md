# v1.14.0 发布说明

## 重点

语音从云端改为**完全本地**：插件通过本机 Mizuoto TTS WebUI 合成，
不再需要 Fish API Key，不按次计费。

## 新增

- 本地语音：Mizuoto `127.0.0.1:7869`，默认模型 `gptsovits/v2pro-base`
- Windows 原生播放（绕开浏览器自动播放限制）
- 中文文字回复 + 日语语音朗读（自动翻译，失败重试 3 次）
- 回复字数上限滑块（20–500 字）
- 语音设置里两个独立开关：
  - 开机自动启动服务
  - 打开插件时加载模型（关闭会立即卸载释放显存）
- Mizuoto 启动脚本路径可配置，适配不同电脑的安装位置
- 端口自动探测 7869 / 7870 / 7871

## 变更

- 预设从四套精简为只有「默认」一套
- README 重写，补充 Mizuoto 安装、模型下载、音色创建、常见问题
- 新增 `docs/SETUP.md` 完整图文步骤
- 明确署名：Mizuoto / Qwen3-TTS / GPT-SoVITS 作者 licyk，插件不包含、不再分发软件和模型

## 修复

- 设置页模型/音色显示旧值
- 长回复语音不触发
- 语音重复朗读上一条
- 回复字数上限保存后回到 120
- 翻译偶发失败导致整条语音不可用
- 「鳕鱼」被误译成香烟

## 安装

```bash
dsh plugin --profile <profile> add "dsh-haruhi-persona-1.14.0.tgz"
```

语音需要另外安装 Mizuoto 和模型，见 `docs/SETUP.md`。

## 已知限制

- 语音播放目前仅 Windows；
- 模型、音色、参考音频需用户自备；
- 翻译需要外网；
- 首次加载模型较慢，之后约 1–2 秒；
- 纯 CPU 合成会很慢。
