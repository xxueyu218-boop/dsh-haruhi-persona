# 安装与运行教程（1.14.0）

这份文档写给第一次安装的人。插件本身只负责人格、界面和语音接线，
**语音软件、模型和音色需要自己准备**。

---

## 0. 整体是怎么运作的

```
DSH + 春日插件
      │  中文回复
      ▼
插件把中文翻译成日语
      │  HTTP POST /v1/audio/speech
      ▼
本机 Mizuoto TTS WebUI（127.0.0.1:7869）
      │  加载 GPT-SoVITS 模型 + 你的音色
      ▼
返回 WAV → 插件用 Windows 原生播放
```

- 不联网也能合成（翻译那一步需要外网）；
- 不调用付费 API，不按次收费；
- 模型和音色都在你自己的电脑上。

---

## 1. 准备

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10/11 |
| DSH | 已安装并能打开 Web UI |
| 显卡 | 建议 NVIDIA，6 GB 显存左右；纯 CPU 会很慢 |
| 磁盘 | 预留 5–10 GB |
| 网络 | 下载模型建议挂代理，否则容易失败 |

---

## 2. 安装 Mizuoto TTS WebUI

### 2.1 下载整合包

打开：

- 整合包 / 文档：<https://licyk.github.io/sd-webui-all-in-one/portable/portable>
- 项目源码：<https://github.com/licyk/qwen-tts-webui>
- 视频教程：<https://www.bilibili.com/video/BV1sr6GB5Emd/>

下载页面里的 **Windows 整合包**（文件名类似 `sd_portable_downloader.bat`，约 129 KB）。

### 2.2 运行安装器

1. 新建一个**纯英文、无空格**的目录，例如 `D:\Mizuoto`；
2. 把 `sd_portable_downloader.bat` 放进去；
3. 双击运行；
4. 在菜单里选择 **Qwen TTS WebUI / Mizuoto TTS**；
5. 等待下载和解压，期间不要关窗口；
6. 完成后目录里会多出一个整合包文件夹（名字类似 `qwen-tts-webui` 或 `Mizuoto-TTS-WebUI`）。

> 安装器只负责部署环境；它本身不是日常启动器。

### 2.3 启动服务

1. 进入刚生成的整合包文件夹；
2. 找到启动脚本（通常叫 `启动.bat`、`start.bat` 或 `launch.py`）；
3. 双击运行；
4. 看到黑窗口输出：

```
Mizuoto TTS WebUI 已启动，访问地址：http://127.0.0.1:7869
```

5. 浏览器打开 <http://127.0.0.1:7869>。

**这个黑窗口不要关**，关掉服务就停了；可以最小化。
第一次启动较慢，等浏览器能打开页面再进行下一步。

---

## 3. 下载语音模型

1. 打开 Mizuoto 的 **模型** 页面；
2. 找到 `gptsovits/v2pro-base`；
3. 点击下载，等待状态变成 **installed**。

说明：

- 模型约 300 MB，加上资源约 1 GB；
- 显存约 2.5 GB，6 GB 显卡够用；
- 签名：`gptsovits/v2pro-base`；
- 下载失败就重试，或在设置里切换 `huggingface` / `modelscope` 源；
- 国内网络建议挂代理，或在启动时加 `--proxy http://127.0.0.1:7877`。

> **可选模型**：也可以下载 `qwen3tts/0.6b-base`（约 2.4 GB，显存约 4 GB）。
> 它不依赖日语前端，兼容性更好，但在 6 GB 显卡上合成明显慢于 GPT-SoVITS；
> 换模型后插件里的「模型 ID」要改成 `qwen3tts/0.6b-base`。

---

## 4. 创建音色

1. Mizuoto → **音色** → 新建音色；
2. 上传 5–10 秒**日语**参考音频（干净人声，mp3/wav；不要音乐、不要混响）；
3. 填写这段音频对应的文本（没有 Whisper 就手动填，必须和音频一致）；
4. 保存后，在音色列表点开该音色，复制 **音色 ID**；
5. 也可以浏览器打开 `http://127.0.0.1:7869/api/v1/voices`，返回 JSON 里的 `id` 就是。

音色 ID 是一串类似 `v1a17...` 的字符，后面要填进插件。

> 只能用你有权使用的声音；克隆真人声音需要本人同意，不要使用音乐平台下载的歌曲人声。

## 5. 安装插件

### 方式一：Release 安装包

1. 下载 `dsh-haruhi-persona-1.14.0.tgz`；
2. 执行：

```bash
dsh plugin --profile <profile> add "下载路径/dsh-haruhi-persona-1.14.0.tgz"
```

### 方式二：仓库源码

```bash
dsh plugin --profile <profile> add link:/path/to/dsh-haruhi-persona
```

安装后在 **设置 → 凉宫春日** 里配置。

---

## 6. 配置插件

打开 **设置 → 凉宫春日 → 语音回复**：

| 设置项 | 填什么 |
|---|---|
| 启用语音 | 打开 |
| 自动朗读 | 想自动出声就打开；关闭则只显示「语音」按钮 |
| Mizuoto 地址 | `http://127.0.0.1:7869` |
| 模型 ID | `gptsovits/v2pro-base` |
| 音色 ID | 第 4 步复制的 ID |
| Mizuoto 启动脚本 | 可选；填 Mizuoto 的启动 `.bat` 路径，插件才能自动启动/开机自启 |
| 回复字数上限 | 建议 80–150 |

点「试听」确认能出声。

---

## 7. 两个显存开关

- **开机自动启动服务**
  - 开：下次开机只启动服务，不加载模型；
  - 关：开机什么都不启动。
- **打开插件时加载模型**
  - 开：插件一打开就预热，首句更快；
  - 关：不预热，第一句语音时才加载。

拨动开关会**立即**生效：

- 打开 → 调 Mizuoto 接口加载模型；
- 关闭 → 调卸载接口，立刻释放显存。

注意：卸载时如果正在说话会中断当前语音。

---

## 8. 使用

1. 输入框左侧点「春日」切到春日会话；
2. 正常聊天，回复是中文；
3. 语音会自动用日语朗读（或点回复下方的「语音」）；
4. 切回普通会话后人格和语音都失效。

## 9. 常见问题

**点语音没反应**
- 看 Mizuoto 窗口是否还在；
- 设置里点「试听」，看是否报错；
- 检查音色 ID 是否填对。

**第一句特别慢**
- 模型在加载，正常；
- 之后约 1–2 秒；
- 可打开「打开插件时加载模型」提前预热。

**提示自动翻译失败**
- 翻译需要外网；检查网络/代理后重试；
- 插件会自动重试 3 次。

**端口被占用**
- 插件会自动尝试 7869/7870/7871；
- 也可以在 Mizuoto 启动参数里换端口，再把地址填进插件。

**显存一直占着**
- 关闭「打开插件时加载模型」会立即卸载；
- 或停用插件/关闭 Mizuoto。
